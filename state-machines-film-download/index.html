What changes

Before
  • A chunk map, sidecar files, 12 booleans and 6 button classes each describe the download.
  • Any run could clear flags that a newer run had set.
  • The map could say done before the bytes were safe.
After
  • Named states for a chunk and for the download, with the moves between them.
  • A run only changes flags while it is current.
  • The map follows the flush, and the button shows one state.

Three fixes are built and tested. The single owner for the preparer's flags is the next step.
