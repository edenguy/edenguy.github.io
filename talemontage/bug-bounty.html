TaleMontage · Bug Bounty

Seven agents.
One queue.

How TaleMontage hunts its own bugs: two AI agents go looking, one turns what they find into a test, and four more judge it, plan the fix, make it and check it. Each part has its own agent and model, and each runs in the background.

No bug is fixed until a test proves it red.
The pipeline

Find, prove, plan, fix, verify

Every hand-off goes through one queue, run by a tested script. The script moves each bug from state to state, fingerprints its proof, and runs every test the agents rely on. The agents make the judgement calls.

Verifier

Checks every fix on its own, without the mitigator. It replays the proof red before the fix, green after, and red again with the fix taken out, then reviews the fix against its contract.

States

The life of a bug

Only the queue's script moves a bug from one state to the next, and only when that agent's step is done. A bug's state changes nowhere else.

scenario→ submitted→ proven→ planned→ fixed→ verified→ merged

Causality

Red, green, red

A test that just passes after a change proves nothing: maybe the test was weak. So the verifier replays the proof three times.

Rules that can't be broken

Guarantees

#

A proof can't change

Every proof is fingerprinted when it's accepted. If any of it changes, the bug stops where it is, so nobody can bend a test to make it pass.

1:1

One bug, one commit

Each fix stays inside the files its contract allows. Any change beyond that is caught at verification.

≠

Nobody grades their own work

The agent that fixes a bug never verifies it, and the agent that finds a bug never decides whether it's real.

?

Product questions go to the owner

When a fix depends on what the product should do, the agent stops and asks instead of guessing.

∞

Every fix stays tested

A merged proof becomes an ordinary regression test, and an audit checks it's still the same test that was accepted.

⏱

Time limits, not quotas

Each hunter works to a time limit. A turn costs the agent's whole context again, so a session's last findings cost the most, and each hunt starts fresh.
